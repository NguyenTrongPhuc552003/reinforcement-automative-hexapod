# Hexapod Utilities

This directory contains utility scripts for the Hexapod Robot Control System.

## Available Scripts
- **install.sh**: Install/remove kernel module
- **monitor.sh**: Monitor system activities

## Usage
```bash
# Install kernel module
sudo ./install.sh

# Remove kernel module  
sudo ./install.sh -r

# Monitor system
./monitor.sh
```
